# Panduan CBT pada iPhone (Safari + Guided Access)

Tidak tersedia aplikasi iOS untuk proyek ini. Panduan berikut hanya memandu penggunaan CBT melalui Safari dan fitur bawaan iOS **Guided Access**.

## 1. Hubungkan ke Wi-Fi sekolah

**Settings → Wi-Fi** → pilih Wi-Fi sekolah → pastikan terhubung.

## 2. Buka CBT di Safari

1. Buka **Safari**.
2. Ketik alamat CBT yang diberikan guru, misalnya `http://192.168.10.1/cbt`.
3. Login menggunakan akun CBT sekolah.
4. Kerjakan ujian seperti biasa.

## 3. Aktifkan Guided Access (sebelum ujian)

1. Buka **Settings → Accessibility → Guided Access**.
2. Aktifkan **Guided Access**.
3. Pilih **Passcode Settings → Set Guided Access Passcode**.
4. Gunakan passcode yang hanya diketahui pengawas ujian.
5. (Opsional) Aktifkan **Face ID / Touch ID to End** agar pengawas lebih mudah mengakhiri.

## 4. Mulai Guided Access saat ujian

1. Buka Safari dan tampilkan halaman CBT.
2. Tekan tombol **Home** tiga kali (iPhone dengan tombol Home) **atau** tombol **Side** tiga kali (iPhone tanpa tombol Home).
3. Ketuk **Options** untuk mengatur keyboard/navigasi bila diperlukan.
4. Ketuk **Start**.

Selama Guided Access aktif, siswa tetap berada di aplikasi yang dipilih hingga pengawas mengakhirinya.

## 5. Mengakhiri Guided Access

1. Tekan tombol Home/Side tiga kali.
2. Masukkan passcode atau gunakan Face ID/Touch ID.
3. Ketuk **End**.

## Keterbatasan penting

- **Guided Access adalah fitur iOS, bukan fitur aplikasi ExamBrowser.**
- PWA atau halaman web di iOS **tidak dapat** memblokir screenshot dan **tidak dapat** mengunci perangkat penuh seperti kiosk.
- Screenshot kontrol sistem iOS (kombinasi tombol) tetap dapat dilakukan; pengawasan langsung tetap diperlukan.
- Aplikasi ini tidak dibuat untuk iOS dan tidak mengklaim kemampuan tersebut.
